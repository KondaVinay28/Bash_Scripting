# Day-34: Returning Values from Functions

This folder demonstrates how function results can be captured using shell variables.

## Files

- `returnvvaluesfromfunctions.sh`

## Concepts covered

- Functions that assign values to variables
- Capturing output from a function using global variables
- Passing input to functions
- Using function results later in the script

## Script summary

### `returnvvaluesfromfunctions.sh`

- Defines `print_message` and passes a value to it
- Stores the result in a variable named `output`
- Prints the value after the function runs

## Key idea

In Bash, functions commonly communicate results through variables instead of a formal `return` value like in some programming languages.

# Day-38: CSV Data Samples

This folder contains sample CSV datasets used for learning how to process structured text and tabular data in shell-based workflows.

## Files

- `sales.csv`
- `sample.csv`

## Concepts covered

- CSV structure
- Delimited data processing
- Common data formats for shell scripting tasks
- Preparing files for parsing with shell tools like `awk`, `cut`, and `sed`

## Data summary

### `sales.csv`

- Large sales dataset with columns such as region, country, item type, units sold, and profit
- Typical example for data analysis and filtering tasks

### `sample.csv`

- Small example containing short records with region, code, name, age, and rating

## Key idea

Structured CSV files are a common input format for Bash scripts when filtering, summarizing, or transforming business data.

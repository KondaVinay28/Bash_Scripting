# Bash Scripting Concepts Index

This repository is a collection of bash scripting exercises, covering everything from the very first `#!/bin/bash` script to loops, functions, file handling, CSV processing, and argument parsing.

Each folder below focuses on a specific learning topic and includes scripts or sample data designed to help practice core shell concepts.

## Learning path

The repository follows a common shell scripting progression:

1. Start with script basics and variables.
2. Understand arguments, conditions, and exit codes.
3. Practice loops, arrays, and iteration.
4. Move into functions and reusable logic.
5. Work with files, networking, and datasets.
6. Learn text processing with `sed` and `awk`.

This structure makes it easy to move from beginner to intermediate shell scripting using the same project as a learning lab.

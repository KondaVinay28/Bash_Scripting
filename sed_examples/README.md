# sed_examples: Stream Editing Fundamentals

This folder contains sample CSV files used to practice text transformations with `sed`.

## Files

- `IndiaSales.csv`
- `UAEsales.csv`
- `sales.csv`
- `modified.csv`

## Concepts covered

- `sed` as a stream editor
- Pattern matching and substitution
- Editing CSV-like data streams
- Filtering lines by content
- Replacing values in bulk

## Example usage ideas

- Replace a country or item label across a dataset
- Delete lines matching a pattern
- Print only selected rows
- Transform file content before further analysis

## Data summary

These CSV files are variations of a sales dataset and are useful for experimenting with text transformations without changing the original structure of the dataset drastically.

## Key idea

`sed` is ideal for quick text manipulation in pipelines, especially when working with files that resemble reports or CSV records.

# Day-24: First Shell Script Basics

This folder introduces the essentials of a Bash script: the shebang, comments, and a basic `echo` command.

## Files

- `hello.sh`

## Concepts covered

- Shebang: `#!/bin/bash`
- Shell comments with `#`
- Executing a script with `./hello.sh`
- Printing text to the terminal using `echo`

## Example script summary

`hello.sh` is the first script in the collection. It prints:

- `Yo...................`

This demonstrates the minimum required structure for a shell script and how to produce output.

## Key idea

A shell script is just a text file that the shell executes line by line. The first line tells Linux which interpreter to use.
